# Shadcn Reinitialization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reinitialize the project's `shadcn/ui` foundation under `src/shadcn`, replace the current pseudo-`shadcn` files, and restore renderer imports onto an official CLI-managed primitive layer.

**Architecture:** Keep the Electron process split unchanged with `src/main`, `src/preload`, and `src/renderer`, while introducing `src/shadcn` as a renderer-only primitive UI layer. Wire `@shadcn/*` through Vite and TypeScript, regenerate the foundation with the official CLI, then migrate renderer imports from the old pseudo paths.

**Tech Stack:** Electron, Vite, React, TypeScript, Tailwind CSS v4, `shadcn/ui`, pnpm

---

### Task 1: Add `@shadcn` Path Resolution

**Files:**

- Modify: `electron.vite.config.ts`
- Modify: `tsconfig.web.json`

- [ ] **Step 1: Inspect the current alias configuration**

Run: `sed -n '1,220p' tsconfig.web.json`
Expected: only `@renderer/*` path mapping exists.

- [ ] **Step 2: Add the Vite alias**

Update `electron.vite.config.ts` so renderer aliases include:

```ts

  '@renderer': resolve('src/renderer/src'),
  '@shadcn': resolve('src/shadcn'),
  '@shared': resolve('src/shared')
}
```

- [ ] **Step 3: Add the TypeScript path mappings**

Update `tsconfig.web.json` so `compilerOptions.paths` includes:

```json
"@renderer/*": ["src/renderer/src/*"],
"@shared/*": ["src/shared/*"],
"@shadcn/*": ["src/shadcn/*"]
```

- [ ] **Step 4: Verify the config edits**

Run: `sed -n '1,220p' electron.vite.config.ts`
Expected: `@shadcn` and `@shared` aliases are present.

Run: `sed -n '1,220p' tsconfig.web.json`
Expected: `@shadcn/*` and `@shared/*` path mappings are present.

- [ ] **Step 5: Commit**

```bash

```
